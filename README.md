# Unit-Converter

A clean, responsive unit converter built with HTML, CSS and JavaScript.

🔗 **[Live Demo](https://vishal912026.github.io/Unit-Converter/)**

## Features
- Length, Weight, Volume, Speed and Temperature conversion
- Instant results as you type
- Swap units with one click
- Copy result to clipboard
- Dark / Light mode (remembers your choice)
- Fully responsive (mobile friendly)

## Tech Stack
HTML5, CSS3, Vanilla JavaScript

## Run Locally
Just open `index.html` in your browser.
